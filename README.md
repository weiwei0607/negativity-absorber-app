## ✨ 為什麼做這個？

市面上大部分「情緒 App」都在教你「想開一點」、「正面思考」。但心理學研究告訴我們：

> **單純宣洩（venting）對減少憤怒無效，甚至可能強化敵意認知。**
> — Kjærvik & Bushman (2024), *Clinical Psychology Review*, 154 篇元分析

「負能量吸收器」的設計哲學是：
- **先接住** — 讓你感到被理解，但不強化負面思緒
- **再梳理** — 幫你把碎片情緒組織成連貫敘事（認知重構）
- **最後陪伴** — 給你具體可行的微型行動，而不是空泛的加油

這背後結合了 **表達性書寫（Expressive Writing）**、**認知行為療法（CBT）**、以及 **AI 對話設計** 的三重框架。

### 三階段對話設計依據

| 階段 | 設計目標 | 心理學依據 |
|------|---------|-----------|
| **Phase 1: 情感驗證** | 讓用戶感到被理解，但不強化敵意 | 情感驗證理論（Linehan, 1993） |
| **Phase 2: 認知重構** | 區分可控/不可控，敘事建構 | CBT 認知重構 + Pennebaker 敘事模型 |
| **Phase 3: 微型行動** | 具體可執行，降低生理喚醒 | 行為活化（Behavioral Activation）+ 正念技巧 |

> 📚 完整文獻研究請見 [`RESEARCH.md`](./RESEARCH.md)

## 🚀 快速開始

```bash
# 1. 克隆專案
git clone https://github.com/yourname/negativity_absorber.git
cd negativity_absorber

# 2. 安裝依賴
flutter pub get

# 3. 設定 API Key（複製範例檔案後填入）
cp .env.example .env

# 4. 執行
flutter run
```
